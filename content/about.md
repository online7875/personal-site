## 一句话

产品经理，长期做 **支付清结算、灵活用工、跨境支付** 这三块"钱怎么流、账怎么对、合规怎么做"的事，最近在补 AI Agent 这一块。

## 我在做什么

- **灵活用工**：从收款、清分、代发到税务合规与开票，把一条涉及多方资金与票据的链路做成可配置的产品能力。
- **支付清结算**：交易、对账、结算、差错处理，关注的是"钱和账能不能对上，出了问题能不能追"。
- **跨境支付**：多币种收付、汇率与通道选择、合规边界。
- **AI 应用**：把 Agent 和自动化塞进真实业务流程里，而不是只做个 Demo。

## 擅长的事

- **复杂业务建模**：把多头对接、多规则并存的业务，拆成边界清晰、可复用的模块。
- **产研管理**：带过 18 人的产研团队，做过从 0 到 1 的产品线，也做过存量系统的重构。
- **跨团队协同**：和财务、法务、合规、银行/通道方对齐口径，是这类产品绕不开的日常。
- **数据与对账**：习惯用 SQL / Python 自己下手查数，而不是等报表。

## 经历

- **灵活用工平台（云账户 / 瑞讯）**：负责灵活用工产品线，覆盖收款、清分、代发、税务合规与发票，产品线年营收规模过千亿。
- **跨境支付（Airwallex / Deel 等合作方）**：参与跨境收付与多币种结算相关产品设计。
- **团队管理**：管理 18 人产研团队，负责产品规划、排期与交付。
